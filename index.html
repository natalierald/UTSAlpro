C++ Essential Cheatsheet

Panduan sintaks cepat algoritma dan pemrograman C++ untuk persiapan ujian.

I/O & Tipe Data Standar
#include <iostream>
#include <iomanip>
using namespace std;

int a; double b; string c;
cin >> a;
getline(cin, c);
cout << fixed << setprecision(2) << b;
Gunakan getline untuk membaca string berpasasi, dan iomanip untuk format desimal.
Struktur Kontrol & Perulangan
// For loop standar
for (int i = 0; i < n; i++) { ... }

// Range-based for (C++11)
for (const auto& x : arr) {
    cout << x << " ";
}
Loop berbasis rentang mempermudah iterasi elemen array/vektor tanpa indeks manual.
Struktur Data Struct & Vector
struct Mahasiswa {
    string nim;
    double nilai;
};

#include <vector>
vector<Mahasiswa> list;
list.push_back({"2401", 95.5});
vector adalah dynamic array yang fleksibel ukurannya di runtime tanpa risiko buffer overflow.
