## 4. Deskripsi singkat program
Sistem Pengelolaan Parkir Kampus merupakan program yang dirancang untuk membantu petugas parkir dalam menghitung biaya parkir kendaraan dan membuat rekapitulasi pendapatan parkir harian. Program ini menerima data berupa nomor kendaraan, jenis kendaraan, lama parkir, serta status kehilangan tiket. Biaya parkir dihitung berdasarkan jenis dan durasi parkir, sedangkan denda ditambahkan apabila tiket kendaraan hilang.

Program ini juga dapat memproses beberapa kendaraan secara berulang hingga petugas memilih untuk mengakhiri proses. Setelah seluruh data kendaraan selesai diproses, program akan menampilkan rekapitulasi yang mencakup jumlah sepeda motor dan mobil, jumlah kendaraan yang kehilangan tiket, pendapatan dari setiap jenis kendaraan, total denda, total pendapatan, serta biaya parkir tertinggi.
