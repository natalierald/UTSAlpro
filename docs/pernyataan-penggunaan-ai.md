3. *"Cara menginput modul b dari word ke github?"*
4. *"Cara memasukkan tabel ke vscode?"*

## 4. Bagian Hasil yang Digunakan
* **Penautan Gambar:** `![Deskripsi Gambar](..\gambar.png)`
* **Struktur Algoritma Deskriptif:** *"Periksa apakah seluruh input valid. Jika input tidak valid atau lama parkir kurang dari atau sama dengan 0, tampilkan pesan kesalahan dan minta pengguna memasukkan kembali data yang benar. Bulatkan lama parkir ke atas menjadi durasi parkir dalam jam penuh, dengan durasi minimum satu jam. Jika tiket hilang, tambahkan denda sesuai jenis kendaraan, yaitu Rp20.000 untuk sepeda motor atau Rp50.000 untuk mobil."*
* **Panduan Konversi Teks Word ke Format Markdown (`.md`):** Agar isi dokumen Laporan Modul B tampil rapi saat dibuka di halaman GitHub, ubah format teks dari Word menjadi Markdown di dalam file bernama `README.md` atau `MODUL_B.md`.

---

## 5. Pemeriksaan dan Perubahan Mahasiswa
* **Pengujian Mandiri:** Mengompilasi dan menjalankan `modul-b.cpp` sendiri, lalu mencocokkan hasilnya dengan perhitungan manual (misalnya motor 3 jam = Rp4.000, mobil 2,5 jam dengan tiket hilang = Rp59.000, total pendapatan Rp95.000).
* **Penyelarasan Variabel:** Menyamakan nama variabel dan format input dengan Modul A.
* **Penyusunan Ulang Narasi:** Menulis ulang penjelasan kode dengan bahasa sendiri setelah memahami alurnya.
* **Verifikasi Rumus:** Mengecek ulang rumus tarif dan denda terhadap ketentuan.
* **Penyesuaian Visual:** Menggambar ulang atau menyesuaikan *flowchart* agar sesuai dengan kode akhir.
* **Pembaruan Kode:** Mengubah atau memperbaiki kode `main()` & kode Modul B secara mandiri.
